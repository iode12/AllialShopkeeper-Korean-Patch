신비한 백발 여상인 (AllialShopkeeper) 한글 대사 패치
대상: Steam 창작마당 3802714533 / 모드 버전 0.1.0

적용 방법
1. 슬레이 더 스파이어 2를 완전히 종료합니다.
2. 압축파일을 반드시 폴더에 모두 풀어 주세요.
3. Apply-Korean.cmd를 더블클릭합니다.
4. 파일 선택 창에서 패치할 모드의 AllialShopkeeper.pck 파일을 선택합니다.
5. SUCCESS: 44 Korean dialogue lines installed. 문구가 뜨면 적용 완료입니다.
6. 게임 언어를 한국어로 설정하고 게임을 실행합니다.

이전에 받은 한글 패치를 이미 적용했어도 같은 방법으로 다시 실행하면 됩니다.
이때 기존 패치가 만든 원본 백업 파일이 필요합니다.

적용 위치 찾기
Steam 창작마당으로 설치한 경우 아래 위치를 찾아보세요.
[Steam 설치 폴더 또는 SteamLibrary]\steamapps\workshop\content\2868840\3802714533\AllialShopkeeper.pck
Steam 라이브러리를 D: 등 다른 드라이브에 설치했다면 그 드라이브에서 찾으세요.
수동 설치한 모드도 AllialShopkeeper.pck 파일을 직접 선택하면 됩니다.
특정 사용자 이름, 드라이브, 설치 경로에 고정되어 있지 않습니다.
선택 창에서 취소하면 아무 파일도 변경하지 않습니다.

공유 방법
이 ZIP 파일을 그대로 전달하세요. 받는 사람도 자신의 모드 파일을 선택하면 됩니다.
번역 데이터와 적용 스크립트만 포함되어 있으므로 원본 모드는 별도로 설치해야 합니다.
별도 Python이나 Node.js 설치 없이 Windows 기본 PowerShell로 실행합니다.

상인 16개, 가짜 상인 28개, 총 44개의 중국어 대사를 번역했습니다.
음성과 DLL에 들어 있는 중국어 설정 메뉴는 번역하지 않았습니다.
원본 대사 키와 텍스트 효과 태그를 보존했습니다.
원본 파일의 버전을 검사하고, 결과 검증을 통과한 경우에만 적용합니다.
기존 파일은 AllialShopkeeper.pck.original-backup으로 자동 백업합니다.
다시 실행해도 백업을 덮어쓰지 않습니다.

원상 복구
게임을 종료하고 AllialShopkeeper.pck.original-backup을 다른 곳에 복사한 뒤
이름을 AllialShopkeeper.pck로 바꿔서 기존 PCK에 덮어쓰세요.

창작마당 모드가 업데이트되거나 다시 다운로드되면 번역이 풀릴 수 있습니다.
다른 버전에서는 설치가 중단됩니다. 그 경우 새 버전에 맞는 패치가 필요합니다.
파일 구조, 대사 키, 효과 태그, 모든 리소스의 해시를 검사했습니다.
실제 게임 실행과 화면 표시는 아직 확인하지 못했습니다.
